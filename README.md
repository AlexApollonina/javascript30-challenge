# javascript30-challenge 🚀

A collection of interactive web components and mini-apps built purely with
**Vanilla JS, HTML5, and CSS3** to practice native DOM events, animations, and
browser APIs (inspired by Wes Bos's _JavaScript30_ challenge).

## 🛠 Completed Projects

| Day    | Project Name        | Live Demo                                                                         | Key Concepts Practiced                                                                    |
| :----- | :------------------ | :-------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------- |
| **01** | JavaScript Drum Kit | [Live Demo](https://alexapollonina.github.io/javascript30-challenge/01-drum-kit/) | DOM manipulation, Keyboard events (`keydown`), HTML5 Audio API, CSS `transitionend` event |

## 💻 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
